# How to use it

There is nothing to set up: install it, and OxiGuitar plays through it. The **Output** list in the player, at the top of the window, picks the device when you have more than one; **System default** follows whatever your system is set to:

![The player bar: play controls, Speed, Level, and the Output list set to System default](images/player-output.png)

**Tools → Plugins…** shows whether the plugin was found and loaded.

## What you can do with it

- Hear a score. OxiGuitar makes the sound, and this plugin hands it to the system.
- Pick the output device, if you have more than one. The player's **Output** list shows the devices this plugin offers.

A score plays through the sound plugin you have installed. See the OxiGuitar manual if you have no such plugin yet. Without an audio output plugin the player buttons stay greyed out, and OxiGuitar says so when it starts.
