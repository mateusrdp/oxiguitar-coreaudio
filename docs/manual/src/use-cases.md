# What you can do with it

- Hear a score. OxiGuitar makes the sound, and this plugin hands it to the system.
- Pick the output device, if you have more than one. The footer's output chooser and **Tools → Plugins…** list the devices this plugin offers.

A score plays through the sound plugin you have installed. See the OxiGuitar manual if you have no such plugin yet. Without an audio output plugin the player buttons stay greyed out, and OxiGuitar says so when it starts.
