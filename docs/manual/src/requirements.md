# Requirements and assumptions

## Requirements

- OxiGuitar 0.11 or later (plugin interface 1.4). See [the OxiGuitar manual](https://mateusrdp.github.io/oxiguitar/).
- macOS, Apple silicon or Intel.

## Assumptions

- Your system's sound is working already. This plugin doesn't repair it.
- The `.pkg` isn't signed or notarised, because the project doesn't pay Apple for that. It installs for you alone, without a password, and a file installed that way isn't quarantined.
